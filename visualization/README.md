# Inspect SSL views in the browser

From the repository root, you can launch the visualization tool using:

```bash
python visualize_views.py --sample-index 0 --seed 42
```

The script reads one nuScenes `LIDAR_TOP` keyframe, runs the existing
`NuScenesSSLViews` pipeline, and opens `http://127.0.0.1:8765/`. The default dataset
root is `$HOME/Datasets/nuScenes`, version `v1.0-mini`. Keep the script
running while using the viewer; stop it with Ctrl+C.

```bash
python visualize_views.py \
  --dataroot $HOME/Datasets/nuScenes \
  --version v1.0-mini \
  --sample-index 10 \
  --grid-size 0.10 \
  --mask-size 0.40 \
  --mask-ratio 0.30 \
  --seed 42 \
  --port 8765
```

Details:
- Use `--sample-token TOKEN` instead of `--sample-index` to inspect a specific
keyframe. 
- Use `--no-browser` to print the URL without launching a browser, or
`--port 0` to select an available port. 
- Training-version metadata also works but
takes longer to index; mini is more convenient for crop inspection.

Without schedule arguments, masking uses a fixed **0.4 m patch width and 0.3
occupied-patch ratio**, configurable with `--mask-size` and `--mask-ratio`.
To inspect Sonata's progressive schedule instead, supply the intended training
length and the step to visualize:

```bash
python visualize_views.py --total-steps 1000 --step 0 --seed 42
python visualize_views.py --total-steps 1000 --step 50 --seed 42
```

The first uses 0.1 m patches and ratio 0.3. The second reaches 0.4 m patches and
ratio 0.7 at the end of the first 5% of training; those values remain fixed
afterward. If omitted in scheduled mode, `--step` defaults to 0. The footer shows
the requested training step and effective masking values. `--total-steps` cannot
be combined with fixed `--mask-size` or `--mask-ratio`, and `--step` requires
`--total-steps`.

The dropdown contains the **original raw scan, two globals, two masked globals
and four locals**. The masked globals use the exact corresponding global view's
points and coordinates; no extra crops or noise are generated by the viewer.

- **Augmented input:** displays each view's `coord`, including its independent
  geometric transformations.
- **Original positions:** displays its corresponding `origin_coord`, making
  crop locations comparable in the original sensor frame. These are the same
  selected points, with their unaugmented positions.
- **Point size:** adjusts the rendered size in pixels.
- **Highlight masked features:** colors selected points pink in masked views.
  All points remain visible; unselected points retain their original-height
  colors. The footer reports the actual masked-point count and fraction, masking
  patch width and requested occupied-patch ratio. The ratio of points can differ
  from the ratio of patches because patch populations differ.
- **Fit view:** fits the camera to the selected cloud. Switching views otherwise
  preserves the camera; changing coordinate representation fits automatically.

Drag to orbit, right-drag to pan, and scroll to zoom. Z is up. Axis colors are
X red, Y green, Z blue. Point colors use original height with one shared scale,
so a point keeps its color after augmentation, except when highlighting masked
features. Pink shows where the model replaces embedded features with its learned
mask token; the viewer displays the original points and does not run the model.
It reads the pipeline's boolean mask rather than generating a separate one.

To inspect an **already generated** result, call the same server directly:

```python
from visualize_views import serve_views

# views = augment(item), generated by your existing code.
serve_views(views, original=item["point"])
```
